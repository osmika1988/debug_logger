使用說明

這是什麼

硬體 Debug Logger 是一個純前端、離線運作的工具，用來管理硬體除錯測試的專案、版本與測試紀錄。所有資料只存在你的瀏覽器或匯出的 JSON 檔案中，不會連線到任何伺服器。

資料結構

專案 → 版本 → 測試紀錄，三層管理：

  • 專案：例如一款產品或一個開發案。
  • 版本：例如 EVT / DVT / PVT 階段，或某個韌體版本。
  • 測試紀錄：每一次除錯過程，包含條件、問題、步驟、觀察、量測與結論。

基本操作

  • 左側「專案」卡片：點「+ 新增」建立專案，點清單項目切換，✎ 編輯、× 刪除。
  • 選擇專案後會出現「版本」卡片，操作方式相同。
  • 選擇版本後主畫面會顯示統計數字與時間軸，可點「+ 新增紀錄」開始記錄。

測試紀錄欄位

  • 標題、狀態（Open / Investigating / Fixed / Verified）、嚴重度（Critical / High / Medium / Low）。
  • 韌體版本／Commit、Root Cause 分類（可自訂並自動記憶）。
  • 附件：可拖放或點擊上傳圖片／檔案，圖片會自動壓縮；點擊可放大預覽。
  • 標籤、關聯紀錄（可標記延續、重現或取代了哪一筆，含跨版本）。
  • 測試條件、問題描述、重現／測試步驟、觀察／量測結果、結論／對策。
  • 結構化量測數值（項目／數值／單位），同名項目跨紀錄累積後可產生「📈 走勢圖」。

搜尋與篩選

  • 搜尋框可全文檢索標題、條件、問題、步驟、觀察、結論。
  • 開啟「跨專案／版本搜尋」可一次搜尋所有資料。
  • 可依排序方式、狀態、嚴重度、日期範圍、逾期未結案天數篩選，並可點擊標籤篩選（可切換 AND / OR 模式）。
  • 「+ 儲存目前條件」可把目前的篩選存成常用篩選 chip，之後一鍵套用。

其他功能

  • 管理標籤：新增、命名、上色、刪除標籤。
  • 比較版本：並列比較兩個版本的紀錄差異。
  • 復原：刪除專案／版本／紀錄／標籤後，畫面下方會出現復原提示，可按「復原」或 Ctrl+Z 還原。
  • 自動備份：編輯中會自動備份到瀏覽器本機儲存；重新開啟頁面若偵測到備份，會提示「還原備份」或「忽略」。這不取代手動存檔。

儲存、開啟與匯入資料

  • 儲存 JSON：把目前所有專案資料下載成一個 .json 檔，請自行妥善保存與備份。
  • 開啟 JSON：讀取先前儲存的 .json 檔，會取代目前畫面上的所有資料。
  • 匯入（專案卡片內）：從另一份 JSON 檔匯入指定專案並合併進目前資料，可勾選要匯入哪些專案，重複命名會提示。

清除瀏覽器資料前，務必先「儲存 JSON」，否則自動備份也會一併遺失。

匯出報告

可匯出 Markdown、CSV 或 PDF，並可選擇匯出全部或勾選部分紀錄；匯出 PDF 時可勾選是否包含圖片附件。

鍵盤快捷鍵

  • / 快速聚焦搜尋框。
  • N 於已選版本時新增紀錄。
  • Ctrl/Cmd + Enter 於編輯視窗中儲存。
  • Ctrl/Cmd + Z 復原上一次刪除。
  • Esc 關閉目前視窗。

其他小工具

右上角可切換淺色／深色主題、收合篩選側欄；「載入範例」可快速瀏覽功能；「新檔案」會清空目前資料重新開始（若有未儲存變更會先提示確認）。

管理標籤

刪除標籤不會移除已套用在紀錄上的標籤文字，只會從篩選清單移除。
